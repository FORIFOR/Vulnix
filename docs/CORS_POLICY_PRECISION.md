# 独立CORSラボ：資格情報付き未信頼オリジン許可

対象は `tests/fixtures/cors_policy_lab.py` の5条件で、検査器とは独立した固定応答を返す。正解ラベルは「未信頼オリジンを資格情報付きで許可するCORSポリシー」だけを脆弱条件とする。公開文書への `*` 許可や資格情報を伴わないOrigin反射を脆弱条件には含めない。

同じ5条件を修正前のPR #64と修正後で1回ずつ実行した結果は [測定JSON](CORS_POLICY_PRECISION.json) に保存した。

| 判定 | 修正前 | 修正後 |
| --- | ---: | ---: |
| TP / FP / FN / TN | 1 / 2 / 0 / 2 | 1 / 0 / 0 / 4 |
| Precision | 33.3% | 100% |
| Recall | 100% | 100% |
| 誤検知率 | 50% | 0% |

各条件への対象GETは1回。追加の対象通信・外部AI呼び出しはない。所有確認済みの診断経路でも、危険条件の所見は監査ハッシュ付きで `detected`、公開文書の `*` はCORS所見なしと確認した。

これは**1分類・5条件の模擬環境**に限る。CORSによる個人情報の漏出を実証した値でも、Web脆弱性全体の精度でもない。危険ポリシーは観測済みだが、具体的な機密応答の読み取りは行っていない。
