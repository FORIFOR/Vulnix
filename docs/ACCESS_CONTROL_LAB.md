# 認証・アクセス制御の独立ラボ比較

## 範囲と正解

対象はループバックに立てた7条件の模擬サーバーです。サーバーと正解表は診断エンジン、Gateway、Worker、ARTEXのコードを参照しません。正解表は [`tests/fixtures/access_control_truth.json`](../tests/fixtures/access_control_truth.json)、サーバーは [`tests/fixtures/access_control_lab.py`](../tests/fixtures/access_control_lab.py) です。

| 条件 | 未認証の保護対象露出 | 他アカウントのデータ取得 |
| --- | ---: | ---: |
| 公開JSON | いいえ | いいえ |
| 認証必須JSON（401） | いいえ | いいえ |
| 未認証公開 | はい | はい |
| IDOR | いいえ | はい |
| 403拒否 | いいえ | いいえ |
| 404拒否 | いいえ | いいえ |
| 紛らわしい200（マーカー文字列を説明文に含む） | いいえ | いいえ |

`未認証公開` の保護対象性は独立した正解表で与えています。実際の公開サイトのJSON応答だけから、この事実を推定していません。したがって、L1のJSON 200はすべて `candidate` です。保護対象を示す独立した契約・所有者提供の仕様がないまま `detected` に昇格しません。この保守的な判定には、未認証公開1件の見逃しという限界があります。

IDORの `proven` は隔離ラボのみです。別アカウントAとして固定パスのBの資源を1回GETし、HTTP 200、固定の検証マーカー、応答の呼出元・所有者・資源IDが同時に一致した場合だけ成立させます。説明文中にマーカーを含む200、403、404は証明になりません。403は今回の条件で `not_reproduced`、404は `unverified` です。これで機密情報の実サイト漏えいを主張しません。実サイトのL2禁止は維持します。

## 同一条件でのローカル測定

コマンド: `VULNIX_NO_ENV_LOCAL=1 python3 -m scripts.bench_access_control`。生データは [`ACCESS_CONTROL_LAB_COMPARISON.json`](ACCESS_CONTROL_LAB_COMPARISON.json) に保存しています。このローカル測定ではARTEXのPythonスタンドインを使い、エンジン表示は `unverified` です。Linux CIではピン留めされた実ARTEXバイナリとローカル模擬モデルで同じ測定を実行します。模擬モデルは全条件に同じIDOR検証を提案するため、採用率は計画の選択精度を意味しません。

| 測定 | 固定L1 | 計画＋Gateway＋隔離Worker |
| --- | ---: | ---: |
| 他アカウント取得 TP / FP / FN / TN | 0 / 0 / 2 / 5 | 2 / 0 / 0 / 5 |
| 他アカウント取得 Precision / Recall | 定義不能 / 0% | 100% / 100% |
| 未認証保護対象露出 TP / FP / FN / TN | 0 / 0 / 1 / 6 | 0 / 0 / 1 / 6 |
| 未認証保護対象露出 Precision / Recall | 定義不能 / 0% | 定義不能 / 0% |
| AI計画の採用率 | 対象外 | 7/7（固定模擬提案） |
| 対象GET | 7回 | 14回 |
| Gateway呼出し / Worker起動 | 7 / 7 | 14 / 14 |
| 平均処理時間 | 0.067秒 | 0.651秒 |
| 状態保存 / 台帳確定 | 21 / 21 | 35 / 35 |
| 実モデル費用 | US$0 | US$0 |

この比較では追加の検証GETとWorkerにより時間が増えています。ローカルのスタンドインはAIを呼ばないため、AIトークン数・推定費用は未計測で、実モデルの採用率・品質も未検証です。生データの `ai_est_tokens: null` と `hypothetical_model_cost_usd: null` はゼロ消費を意味しません。

## 安全性とUIの確認

Gatewayは各GETについて範囲と権限を再検証し、ARTEXにはWorkerを直接起動する権限がありません。所有確認・期限切れ・組織分離・監査・緊急停止の既存回帰テストを全バックエンドテストで実行します。ラボのL2はテスト用のループバック隔離のみです。

CORSの390px本番ビルドで、観測ヘッダー、未実証の機密読取に関する説明、証拠の詳細、横スクロールなしを確認したスクリーンショットは [`CORS_390_RESULT.png`](CORS_390_RESULT.png) です。実サイトでの所有確認、診断通信、実Abliteration AI、実サイトL2はこの測定の対象外です。
