# 外部承認・設定が必要な項目

判定の正本は [GOAL_COMPLETION_MATRIX.md](GOAL_COMPLETION_MATRIX.md)。ここに列挙した項目だけを待ち、模擬環境で進められる開発・監査・テストは継続する。

| 項目 | 現在の不足 | 進める条件 |
| --- | --- | --- |
| 実Abliteration AIの追加評価 | 元ツリーの保護された設定から鍵は利用可能。別々に承認された2回はいずれも推論トークンだけでJSON本文なし。両方の消費記録を保存済み。新しい`json_object`要求と推論設定候補は[未送信契約](ABLITERATION_OUTPUT_CONTRACT.md)に別SHA・費用予約で記録 | 対象モデルで推論制御が有効かは未確認。新しい有料要求のモデル・全送信内容・SHA・回数・費用上限を所有者が別途承認するまで送信しない |
| 公開βの実DNS所有確認・許可済み実サイトE2E | 実際の公開βバックエンドで所有確認を完了した証拠と、対象・範囲・通信上限・実行期間が揃っていない | 所有者設定と明示的な実行承認の範囲でのみ、読み取り専用L1を実施。所有確認前は診断通信なし |
| GitHubの正式独立レビュー | PR #85の正式レビュー0件。リポジトリの確認できるコラボレーターは所有者のみ | 独立レビュアーにアクセス・レビューを依頼できる状態。別エージェントの読み取りレビューはApprove扱いにしない |
| mainへのマージ・本番反映・DNS変更 | 事前承認なし | コード・品質・安全・公開ゲートを揃えた具体的な変更内容に対する所有者承認 |
| Google Search Consoleの公開βE2E | 固定ホスト、Google Cloud OAuth設定、管理権限が未確定 | 既存連携の設定権限と必要な設定。未設定ならGoogleボタンは出さずDNS・ファイル方式を維持 |

実サイトL2は承認だけで有効化しない。別途の安全検証まで禁止を維持する。
