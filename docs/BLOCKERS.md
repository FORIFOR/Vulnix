# 外部承認・設定が必要な項目

判定の正本は [GOAL_COMPLETION_MATRIX.md](GOAL_COMPLETION_MATRIX.md)。ここに列挙した項目だけを待ち、模擬環境で進められる開発・監査・テストは継続する。

| 項目 | 現在の不足 | 進める条件 |
| --- | --- | --- |
| 実Abliteration AIの多段階ARTEX・日本語解説評価 | 固定14条件の検査選択は3回目（候補B：`response_format: {"type":"json_object"}` + `reasoning_effort: "none"`、SHA `7a527a487a309962867f7d02096e527259946f2b62fdbf802a450d386e3803e5`）で **JSON採用 1/1（通算1/3）・TP=8/FP=0/FN=0/TN=6（Precision/Recall/F1 = 1.000）** を実証済み（3承認すべて消費済み）。一方、14条件以外の分類、多段階ARTEXツール呼び出し、および日本語解説（`ExternalAbliterationAdvisor`）の実API送信は未測定 | 追加の実API評価を行う場合は、対象・要求SHA・回数・費用上限について所有者の新たな明示承認が必要（未承認時は内蔵解説と固定L1フォールバックを維持） |
| 公開βの実DNS所有確認・許可済み実サイトE2E | 実際の公開βバックエンドで所有確認を完了した証拠と、対象・範囲・通信上限・実行期間が揃っていない | 所有者設定と明示的な実行承認の範囲でのみ、読み取り専用L1（`VULNIX_REAL_SERVICE_DIAGNOSIS=l1`、最大2 GET）を実施。所有確認前は診断通信なし |
| GitHubの正式独立レビュー | PR #85の正式レビュー0件。リポジトリの確認できるコラボレーターは所有者のみ | 独立レビュアーにアクセス・レビューを依頼できる状態。別エージェントの読み取りレビュー（208ファイル中206件照合済み）はApprove扱いにしない |
