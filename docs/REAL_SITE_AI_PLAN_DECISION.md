# 実サイト向け AI 計画の判断（2026-11-15）

## 現在公開中のβ版

公開中のβ版の実サイト診断は、所有確認と範囲確認の後、公開ページを1回取得して設定を調べる読み取り専用の処理です。診断手順は内蔵ルールで決まり、ARTEX 本体は実サイトの計画に使用しません。IDOR や SQL インジェクションは実サイトでは検査せず、ラボ固有の候補は実サイトの結果に出しません。`VULNIX_REAL_SERVICE_DIAGNOSIS=l1` でも実サイトのL2と修正後再検証は拒否します。

個別所見のAI解説には、運用者が `VULNIX_REAL_SITE_SAFE_AI=1` を明示的に設定した場合だけ使う経路をDraft PRで追加しました。モデルへ送るのは匿名参照IDとコードで固定した規則・分類・深刻度・判定・判定根拠・CVE ID・丸めた点数・KEV真偽だけです。質問文、対象名、URL、証拠、応答本文、認証情報は送信しません。送信前の監査記録が失敗したら送信せず、出力は許可済みの主張・修正案カタログで検証します。初期状態では無効であり、実サイトでの動作は未確認です。

後続のDraft PRでは、公式Abliteration AIへの解説送信に組織ごとの累計予算を追加した。`VULNIX_ADVISOR_PRICE_MODEL` を実際のモデル名に一致させ、`VULNIX_ADVISOR_MAX_COST_USD`、`VULNIX_ADVISOR_USD_PER_1K_INPUT`、`VULNIX_ADVISOR_USD_PER_1K_OUTPUT` の3値を運用者が正の料金として設定しない限り送信を拒否する。送信前に要求のUTF-8バイト数と最大出力2,048トークンから最悪値を算出し、監査ログへ永続的に予約する。同時要求は監査ログのロックで直列化し、再起動後も予約済み額を合算する。モデル応答が失敗・不採用でも予約は戻さない。これは**設定料金とAPI側の出力上限が正しい場合の送信予算**であり、請求額を取得・照合する機能ではない。公開βでは設定せず、実Abliteration AIへの新規呼び出しは行っていない。

## ARTEX をそのまま有効化できない理由とDraft PRの経路

ARTEX の複数ターン計画はモデル呼び出しを前提とします。対象 URL、取得した応答、所有者情報、証拠を含む要求を外部モデルへ転送すれば、サイトの情報を第三者へ送信します。既存の Planner LLM Gateway は実サイト名を含む要求を遮断します。Draft PRでは、実サイトの代わりに合成対象 `lab.test` と匿名化した実測所見の固定項目をARTEXへ渡し、隔離したARTEX本体とループバックのモデルで計画を作る任意の経路を追加しました。計画項目の実行権限はARTEXに与えず、Gatewayが許した読み取り専用のL1だけをWorkerで実行します。実サイトのL2は禁止のままです。

## 将来の成立条件

実サイト固有の AI 計画には、対象情報を外へ送らないモデルと、入力・出力の検証が必要です。Draft PRの経路は模擬環境の実ARTEXとLinuxの隔離検証まで確認しました。所有確認済み実サイトでの通し動作、モデルの計画品質、診断精度の改善は未確認です。

外部の Abliteration AI を実運用で使うには、対象所有者による送信同意、実モデルで採用可能な日本語解説が得られることの確認、利用回数・費用上限の確認が残っています。実サイトへの診断通信は行っていません。

## 承認済みの実モデル試行（模擬所見のみ）

所有者の承認を受け、`abliterated-model` に模擬所見1件の固定列挙値だけを1回送信しました。入力858・出力768トークンで、モデルから応答はありましたが、検証器が1件を拒否し、採用可能な解説は0件でした。拒否の詳細理由は記録していないため、この試行での原因は断定できません。

追加の1回について別途承認を受け、同じ固定項目にJSON形式指定と出力上限2,048トークンを設定して送信しました。応答の終了理由は `length` で、出力2,048トークンはすべて推論用と報告され、解説本文は返りませんでした。検証器の拒否理由は `root:schema: expected exactly {"advice": [...]}` です。2回とも採用可能な日本語解説は0件です。[公開料金表](https://abliteration.ai/pricing/)に基づく概算は1回目約US$0.0032、2回目約US$0.0070、合計約US$0.0102です。これ以上の有料呼び出しは行っていません。
