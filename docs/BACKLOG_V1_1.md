# v1.1 以降のバックログ（v1.0 の完成を妨げないもの）

2026-11-22。v1.0（認可ラボ版）の範囲から外したものです。v1.0 で P0（重大）な障害が見つからない限り、ここに追加し、v1.0 の作業では扱いません。

## AI 診断の精度

| 項目 | 内容 | 前提 |
| --- | --- | --- |
| 外部モデルとの比較 | Abliterated Model・Abliterated Large v2・Claude を、凍結した判定器と未見ケースで比べる | 人による署名（v1.0 の A1）、送信の承認（送信先・要求の SHA・回数・費用の上限） |
| 判定器の追加の研究 | v5 で見逃した形を改善する。対象は、64 KB を超える本文、修正後の確認、base64、A を名乗るページ。v6 の作成も含む | v5 の判定器を v1.0 として固定したあと。改善したら、新しい未見ケースで評価し直す |
| 負例の判定の改善 | v4・v5 では、負例の多くを判断不能のまま残している（負例23件のうち、判定できたのは5〜6件） | 誤った「安全」判定を0のまま保つこと |
