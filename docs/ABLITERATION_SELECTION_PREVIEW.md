# Abliteration AI 検査選択評価の送信前プレビュー

この資料は **実モデル未実行** の評価準備です。実サイト、実モデル、有料 API への通信はありません。

## 固定入力と採点

- PR #67 の独立した14条件を、匿名の `C01`〜`C14` に変換します。
- モデルへ渡す項目は、所有者が提示したルートと資源の認証要件、およびPR #67の実ARTEXラボ測定記録に残ったアカウント資源リンクの観測結果だけです。対象名、ホスト名、URL、パス、認証情報、個人情報、応答本文、秘密、正解ラベルは送りません。
- 正解は `tests/fixtures/access_control_truth.json` に残し、送信内容と分離します。モデルは「別アカウントの資源を読み取り専用で確認する検査候補」を選ぶだけで、脆弱性判定や実行権限は持ちません。
- 応答は `{"selected":["C01", ...]}` だけを受け付けます。未知のID、重複、余分な項目、説明文、JSON以外は不採用です。
- 評価指標は検査選択の TP/FP/FN/TN、Precision、Recall、不要な検査率、応答採用率、呼び出し回数、使用トークン、推定・実費用、所要時間です。実モデル実行時にはモデルの生応答を検証してから採点し、実行計画への採用やWorker起動とは区別します。

## 実モデル評価の実施条件

有料 API 1回・上限 US$0.01 と、上記ハッシュに一致する固定要求の送信は所有者から承認を得ました。`run_approved()` は送信直前に同じ Gateway で再プレビューし、ハッシュを照合します。既存の監査ログへ送信メタデータを記録できない場合は送信せず、モデルへの通信は1回に制限します。応答が不正な場合は不採用として記録し、脆弱性判定や検査実行には渡しません。実モデル応答の採用率、選択精度、トークン、費用、時間は実行後に記録します。実サイト通信、実サイトL2、計画の自動実行は行いません。

この開発環境にはAPI鍵が設定されていないため、承認後も実モデル呼び出しは未実施です。秘密設定ファイルは開いていません。
