# 未見ケース v3 の正解ラベル：人によるレビュー用シート

`python3 -m scripts.make_label_review_sheet --set holdout_v3` で作りました。手で書き換えないでください。

## 進め方

1. 各ケースについて、サーバーの応答を読み、作成者のラベルと2人目のラベルが正しいかを判断します。
2. 結果を「人の確認」欄に書きます。正しければ OK、直したいラベルがあればその内容を書きます。2人のラベルが食い違うケース（**不一致**の行）は、特に確認してください。
3. ラベルを直す場合は、`tests/evaluation/fixtures/holdout_v3_truth.json` を直す PR を別に作ります。直すとハッシュが変わり、評価もやり直しになります。
4. `docs/evaluation/label_signoff_holdout_v3.template.json` を `label_signoff_holdout_v3.json` に写して記入します。
5. `VULNIX_NO_ENV_LOCAL=1 python3 -m scripts.run_model_evaluation signoff-check --set holdout_v3` で、署名が有効かを確かめます。

AI（開発エージェントを含む）は、この確認と署名を代行しません。

## 署名に書く値

- 正解ラベルのファイル：`tests/evaluation/fixtures/holdout_v3_truth.json`
- その SHA-256：`32b1f16b7671b2839ec53f70926acddf63a952242d9f293b38263dae842adddc`

## ラベルの読み方

| 列 | 意味 |
| --- | --- |
| 他アカウント | A が B の機密の記録を読めるか（所有者の規則を踏まえて） |
| 認証なし | 認証なしの要求で、B の記録を読めるか |
| 修正 | 修正後の状態（修正済み／未修正） |
| 保留 | どの検査者が集められる証拠でも決められず、判断を保留するのが妥当か |
