- **区間**（固定ルール）：正解率 0.833 の 95% Wilson 区間は [0.664, 0.927]、Recall 0.80 の区間は [0.49, 0.94] です。誤検知0件でも、誤検知率の上限は 0.16 までしか言えません。
- **正解しなかった5件**：どれも誤検知ではなく、判断の保留です。
  - 200 のログイン画面（holdout-001）と、200 のエラー本文（holdout-013）は、判定器が「200 だが確認できない」として保留しました。
  - 常に429（holdout-007）と、所有者本人の対照がない（holdout-029）ケースは、保留が妥当なケースです。
  - 身元を無視するサーバー（holdout-030）は、判定器が「成立」を確認できませんでした。
- **このことからわかること**：残りの誤りは、検査の選び方ではなく、固定判定器の規則の範囲（偽装した 200 と、身元を無視するサーバー）によるものです。実モデルを入れても、この5件は判定器を変えない限り同じ結果になる見込みです。
- **台本モデルについて**：ローカルの台本モデルは固定の表と同じ検査を選ぶので、結果は同じです。実モデルの価値は、まだ測っていません。

## 4. 3モデルの経路の確認（模擬転送）

- 修正後の確認まで、正しく進むこと

- ループバック以外の転送は、DRY RUN の台帳では送信されないこと
