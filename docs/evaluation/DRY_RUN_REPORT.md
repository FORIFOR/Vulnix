### 3.4 前回の表との違い

最初の版の表（PR #98 の最初のコミット `e69e5f0`）には、「正解・誤検知・見逃し・判断不能」を並べていました。ただし、「見逃し」は混同行列の FN（保留を含む）、「判断不能」は最終状態が判断不能・未検査の件数で、両者は重なっていました。たとえば固定ルールでは、holdout-029 と 030 の2件が、「見逃し 2」と「判断不能 5」の両方に入っていました。そのため、合計は 25 + 0 + 2 + 5 = 32 となり、30になりませんでした。
